Project 02 · QuestaSim parallel simulation initiative C++20 coroutines · thread pool · research prototype

Parallel Simulation Kernel: a coroutine-based discrete-event simulator

  • At every time slot, many independent processes are ready at once.
  • Questa runs them one after another on a single kernel thread.
  • The prototype converts SystemVerilog processes into C++ task functions and runs them in parallel on threads.
  • One sync before the next slot: correct, deterministic, LRM-compliant.

Project 03 · QuestaSim parallel simulation initiative CUDA · performance prototype

GPU-accelerated simulation prototype

  • One time slot: thousands to millions of processes, same function, different data.
  • Every cycle: fresh data host → device, one kernel over all of it in parallel, results back.
  • Large gain over the CPU prototype and standard Questa, identical results.
